♻️ Sıfır Atık Okulu

Öğrencilere geri dönüşüm ve atıkların doğru şekilde ayrıştırılması konusunda temel bilgiler kazandırmak amacıyla geliştirilmiş interaktif bir eğitim web sitesidir.

Bu proje, Biyoloji Öğretmenliği okuyan bir arkadaşımın öğrencilerine yönelik hazırladığı eğitim projesine destek olmak amacıyla geliştirilmiştir.

Web sitesi üzerinden öğrenciler:

* Geri dönüşümün neden önemli olduğunu öğrenebilir.
* Atıkların doğru şekilde ayrıştırılması hakkında fikir edinebilir.
* İnteraktif bir oyun ile farklı atıkların hangi geri dönüşüm kutusuna atılması gerektiğini öğrenebilir.

🎮 Geri Dönüşüm Oyunu

Projenin temel özelliklerinden biri interaktif geri dönüşüm oyunudur.

Oyunda öğrenciye atığın özellikleriyle ilgili sorular sorulur. Verdiği cevaplara göre atığın hangi geri dönüşüm kutusuna atılması gerektiği belirlenir.

Oyunda temel olarak şu geri dönüşüm kutuları bulunmaktadır:

* 🟦 Cam Kutusu
* 🟨 Metal Kutusu
* 📄 Kağıt Kutusu
* 🥤 Plastik Kutusu

Öğrenci soruları cevapladıktan sonra sistem sonucunu gösterir ve neden o kutunun seçildiğine dair kısa bir açıklama verir.

🌱 Web Sitesi İçeriği

Ana Sayfa

Ana sayfada öğrencileri karşılayan bir giriş bölümü ve geri dönüşümün önemini anlatan bilgiler bulunmaktadır.

Ayrıca öğrencinin oyuna geçebilmesi için yönlendirme bölümü yer almaktadır.

      ↓

Neden Geri Dönüşüm?

▶️ Projeyi Çalıştırma

Projeyi bilgisayarda çalıştırmak için öncelikle Node.js ve npm’in kurulu olması gerekir.

Proje klasöründe terminali açtıktan sonra gerekli paketleri yüklemek için:

npm install

Ardından geliştirme sunucusunu başlatmak için:

npm run dev

komutu çalıştırılabilir.

Terminalde verilen local adres tarayıcıda açılarak web sitesi görüntülenebilir.

📱 Responsive Tasarım
